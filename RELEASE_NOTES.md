# Research code v1.0.0

Initial archive of the existing HRS and CHARLS adapted hBCS research code.

- Includes 23 unmodified statistical, preparation, and historical presentation scripts.
- Documents source inputs, dependencies, analysis coverage, and measurement rules.
- Provides four-author citation metadata and the MIT License.
- Includes no participant-level data, manuscripts, confidential comments, or access credentials.
- Excludes death-reclassification, short death-interval, and full CHARLS complete-score selection-weighting analyses.

No statistical analyses were rerun for repository publication. This archive
does not claim that every historical analysis or final presentation can be
reproduced in a single automated run; see `docs/ANALYSIS_COVERAGE.md`.
